# Implementation guidance

- Always solve problems with general algorithms that cover the relevant class of inputs.
- Never implement case-by-case solutions, hardcoded answers, or special rules tailored to individual examples. A reported example is a regression case, not the boundary of the implementation.
- Fix the underlying algorithm or abstraction, and test representative variations beyond the reported example.
- State unsupported input classes and algorithmic limits explicitly instead of adding isolated exceptions to hide those limits.
